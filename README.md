# 合成显微镜与样件台现场联调

本机合成会话由各设备、值班台或实验终端发出。field-session.json 保存设备登记和现场消息。events 内每项依次给出接收时点、发送方、消息类型和负载。接收时点与设备观测时点可以不同。相同接收时点按清单顺序发出。

坐标为样件平面的整数格。光功率和剂量用合成单位，光斑由矩形和功率分布表示。像点允许合成摘要标记。

## 消息与连接

各发送方有独立的 TCP 连接，使用 UTF-8 JSON Lines。每条请求含 at、actor、kind、data，接收方应返回一行 JSON 对象。inventory 是设备登记消息。disconnect 关闭发送方连接，由联调发送程序处理，之后的下一条消息重新建连。段内来源身份取消息和实际设备回报，不能以 TCP 端口替代。发送器按清单顺序运行，跳过场景的实际等待时间。

## 运行

使用 Python 3.11 标准库。运行 python lab_peer.py --check 可以只读核对会话；运行 python -m unittest discover -s tests -v 将启动临时 TCP 回环端，验证会话投递、截断检测及发件端重连。装好接收端后运行 python lab_peer.py --host 127.0.0.1 --port 8765 投递场景并逐行查看响应。回环端仅回显消息，联调工具不作现场业务判断。
